Afin d'executer les executables : 
1. Pour executer le dossier ROM : utiliser un émulateur Gameboy (mgba.io par exemple).
2. Pour executer le dossier WEB : Ouvrir le dossier "web" sur votre terminal (MacOS) et lancer http://localhost:8000 sur votre navigateur.
                                  Sur windows installer l'extension Live Server et ouvrir "index.html" sur votre navigateur.
Choisissez en un seul seulement.
